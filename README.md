# Web Development Fundamentals

A collection of standalone HTML pages for practicing foundational web development concepts. The project uses plain HTML and local or remote media files, with no build tools or external dependencies.

## Topics

- `index.html` - Basic landing page structure
- `textformatting.html` - Common text-formatting elements
- `hyperlink.html` - Links and navigation
- `images.html` - Images and image attributes
- `audio.html` - Audio playback
- `videos.html` - Video playback
- `lyrics.html` - Structured lyrics content
- `favicons.html` - Favicon setup
- `landing/` - Local media and image assets

## Run Locally

1. Clone or download this repository.
2. Open any `.html` file directly in a web browser.
3. Use the browser's developer tools to inspect the HTML and experiment with the examples.

A local development server is optional. For example, with Python installed:

```bash
python -m http.server
```

Then open `http://localhost:8000` in your browser.
